# Consultation and Referral Rules

Purpose: Explains how a doctor asks a specialist for advice, how the specialist replies, and when a consultation request is cancelled.

## Raising a consultation request

A doctor raises a consultation request for one hospital admission and must give a reason. The reason tells the specialist what advice the doctor is asking for. A consultation request with a blank reason is not accepted.

## Specialist response to a consultation request

A specialist answers a consultation request by giving a recommendation. The recommendation is written advice for the doctor who raised the request. A specialist recommendation is not an order, so the requesting doctor decides whether to follow it.

## Cancelling a consultation request raised by mistake

A consultation request that was raised by mistake can be cancelled. Only the doctor who raised the request should cancel it, and only before a specialist has responded. After a specialist has responded, the consultation request stays on the record as answered.

## Automatic cancellation when the admission is not active

A consultation request is cancelled automatically when its admission is no longer active, for example after the patient is discharged. This applies to requests that are still waiting for a specialist response. A specialist cannot respond to a cancelled consultation request. If advice is still needed, the doctor raises a new consultation request under an active admission.

## Consultation recommendations and other decisions

A specialist recommendation does not schedule a surgery and does not approve a discharge. Only the assigned doctor can schedule a surgery or approve a discharge, whatever a specialist recommends. The assigned doctor stays responsible for both decisions.

## AI suggestions about consultations

Any AI output about a consultation request or a specialist recommendation is advisory only. A doctor, nurse or specialist reviews it and makes every decision. AI does not raise, answer or cancel a consultation request.
