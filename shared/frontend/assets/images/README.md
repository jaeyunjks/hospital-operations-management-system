# Shared Images

Images and illustrations shared across hospital modules (logo marks, empty-state
artwork, and similar).

## Conventions

- Prefer **SVG** for logos and illustrations; use PNG/WebP only for raster art.
- Keep files small — compress before committing.
- Every `<img>` needs meaningful `alt` text, or `alt=""` when purely decorative.
- Do not commit patient data, screenshots containing real records, or any
  licensed image without a clear right to use it.
